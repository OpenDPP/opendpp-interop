# OpenDPP™ brand assets

Official logo and social artwork for **OpenDPP**, a product of **Opendpp UAB**.
Everything here is generated from the single vector source
[`logo/opendpp-mark.svg`](logo/opendpp-mark.svg) (the app favicon / brand mark), so
it stays crisp at any size.

> Use of these marks is governed by [`../TRADEMARK.md`](../TRADEMARK.md). The Apache-2.0
> license on this repo covers the **code**, not the **name or logo**. Don't use the
> OpenDPP name or mark to identify a fork, product, or service.

## Logo mark — `logo/`

| File | Size | Use |
| --- | --- | --- |
| `opendpp-mark.svg` | vector | Master source — prefer this wherever SVG is accepted |
| `opendpp-mark-2048.png` … `-400.png` | 2048 / 1024 / 512 / 400 px | Rounded mark, **transparent** corners — light/dark backgrounds, app icons, slides |
| `opendpp-mark-fullbleed-2048.png` … `-512.png` | 2048 / 1080 / 512 px | Gradient **edge-to-edge** — profile pictures that crop to a circle (X, Instagram, LinkedIn) |

## Social lockups — `social/`

Wordmark lockup (mark + "OpenDPP" + tagline), sized per platform.

| File | Dimensions | Platform / placement |
| --- | --- | --- |
| `x-header-1500x500.png` | 1500 × 500 | X (Twitter) profile header |
| `facebook-cover-1640x624.png` | 1640 × 624 | Facebook Page cover (content kept in the mobile-safe centre) |
| `youtube-banner-2560x1440.png` | 2560 × 1440 | YouTube channel banner (content inside the 1546 × 423 all-device safe area) |
| `github-1280x640.png` | 1280 × 640 | GitHub org/repo social-preview image |
| `instagram-1080x1080.png` | 1080 × 1080 | Instagram square card (stacked lockup) |
| `wordmark-horizontal.png` | 1600 × 480 | Reusable horizontal wordmark, **transparent** background |

For the **profile picture** on each platform, pair these banners with a
`logo/opendpp-mark-fullbleed-*.png` (circular crop) or `opendpp-mark-*.png` (square).

**Open** (ink) + **DPP** (green).
